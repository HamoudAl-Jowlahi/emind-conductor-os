## المرحلة 0 — قبل أي سطر كود (يوم واحد)

### 0.1 الترخيص — الأهم على الإطلاق

| الفحص | النتيجة الحالية |
|---|---|
| ملف `LICENSE` | غير موجود |
| حقل `license` في package.json | غير محدد |
| `private` | `true` |

غياب الترخيص = **جميع الحقوق محفوظة للمؤلف الأصلي**. وصف README بأنه "open-source" ليس ترخيصاً قانونياً.

**الإجراء:**
1. ارجع لمصدر التحميل وتحقق من الترخيص هناك
2. إن كان MIT/Apache → أضف `LICENSE` **مع إبقاء إشعار المؤلف الأصلي**
3. إن لم يوجد → راسل صاحبه أو أبقِ المستودع `private` نهائياً

### 0.2 فحص الأسرار

`lib/creds.ts` يقرأ مفاتيح حقيقية من جهازك. قبل أول `commit`:

```bash
git check-ignore -v .env.local data/founder-os.db
```

يجب أن يخرج كلاهما مُتجاهَلاً. سر واحد يُرفع = يبقى في تاريخ Git للأبد.


فائدتها المزدوجة: تنظّف مشروعك، **وتحوّله إلى قالب قابل لإعادة البيع** لاحقاً — كل مشترٍ يستبدل `content.ts` فقط.

**التوصية:** ابدأ بـ Vercel AI Gateway لأن الكود مبني عليه أصلاً.

> ⚠️ أسعار وشروط الطبقات المجانية تتغير باستمرار — **تحقق بنفسك قبل الاعتماد على أي رقم هنا.**

### مؤجّل بقرار منك (2026-08-20) — تقوية المصادقة

المصادقة الأساسية تعمل، وهذه الطبقة الثانية متفق على تأجيلها:

| البند | لماذا يهم |
|---|---|
| تحديد معدل محاولات الدخول (rate limiting) | بدونه تخمين كلمة المرور بلا سقف |
| اشتراط تعقيد كلمة المرور | الحد الحالي 10 محارف فقط |
| استرجاع كلمة المرور | لا توجد وسيلة استرجاع إطلاقاً اليوم |
| تحقق بخطوتين (2FA) | يلزم قبل أي تعريض للإنترنت |
| سجلّ دخول (audit log) | من دخل ومتى ومن أين |

**هذه كلها إلزامية قبل تعريض النظام للإنترنت.** مقبول تأجيلها ما دام على شبكة موثوقة.
